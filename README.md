# Claude Code Plugins by Ankur Agarwal

A plugin marketplace for Claude Code with productivity and creative tools.

## Available Plugins

| Plugin | Description |
|--------|-------------|
| **gmail-cleanup-skill** | Gmail inbox cleanup — scan, classify senders, bulk trash, create filters, and auto-unsubscribe |
| **gemini-image-gen** | Image generation using Google Gemini — prompt crafting, style management, and iterative refinement |

## Installation

Add this marketplace to Claude Code:

```
/plugin marketplace add ankuraa-93/claude-plugins-marketplace
```

Then install the plugins you want:

```
/plugin install gmail-cleanup-skill@ankuraa-93-plugins
/plugin install gemini-image-gen@ankuraa-93-plugins
```

## Usage

After installation, invoke the skills:

```
/gmail-cleanup-skill:gmail-cleanup
/gemini-image-gen:image-gen
```
